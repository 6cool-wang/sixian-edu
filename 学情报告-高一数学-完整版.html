一、逐题深度分析（7 处失分点）

第 5 题 · 三角函数象限符号（单选 5 分） | 概念混淆 · 基础题

题目：已知 sin α = 3/5 且 α 在第二象限，求 cos α。

✗ 学生作答
cos α = √(1 - sin²α) = √(1 - 9/25) = 4/5
✓ 正确答案
第二象限 cos 为负 → cos α = -4/5

错误根源：只知道用平方关系求值，但忘记根据象限判断正负号。"sin²α + cos²α = 1"开方后有正负两个解，必须结合象限取舍。这是高一最不该丢的基础分。

第 7 题 · 三角函数图像平移（单选 5 分） | 概念混淆 · 基础题

题目：将函数 y = sin 2x 的图像向左平移 π/6 个单位，所得图像对应的函数是？

✗ 学生作答
y = sin(2x + π/6)
✓ 正确答案
y = sin[2(x + π/6)] = sin(2x + π/3)

错误根源："左加右减"是针对 x 本身，不是针对整个自变量。当 x 前有系数 ω 时，必须先把表达式写成 sin[ω(x + φ/ω)] 形式，再判断平移量。

第 10 题 · 三角函数性质多选题（多选 5 分，得 2 分） | 审题不细 · 多选题策略

考查点：三角函数 f(x) = 2sin(2x + π/3) 的对称轴、对称中心、单调区间、最值点四个选项判断。

错误表现：学生判断出两个正确选项后，对第三个选项犹豫最终漏选。多选题"少选得 2 分、选错 0 分"的策略不清晰，该选的不敢选。

策略建议：多选题宁可少选不要错选。但你少选的恰恰是对的——这说明知识掌握不够自信。复习对称轴方程 x = π/12 + kπ/2 的求法。

第 12 题 · 向量数量积与几何综合（单选 5 分） | 解题策略不当

考查点：在几何图形中建立坐标系，用向量数量积求解角度关系。

错误表现：建系原点选在正方形中心而非顶点，导致四个顶点坐标都带参数，计算量翻倍。正确的做法是以一个顶点为原点，两条边为轴。

第 14 题 · 已知 tan 求 sin/cos 值（填空 5 分） | 公式误用 · 中档题

题目：已知 tan α = 2，且 α 在第三象限，求 sin α + cos α 的值。

✗ 学生作答
sin α = 2/√5, cos α = 1/√5 → 和为 3/√5
✓ 正确答案
第三象限 sin 和 cos 都负
sin α = -2/√5, cos α = -1/√5 → 和为 -3/√5

错误根源：用 tan α = sin α / cos α 配合平方关系求值时，需联立解出 sin²α 和 cos²α，再结合象限定符号。该生跳过了象限判断，直接取了正数。

第 15 题 · 三角恒等变换大题（解答 13 分，得 4 分） | 公式误用 · 中档题

题目：已知函数 f(x) = sin x - √3 cos x，求 f(x) 的周期、振幅和初相。

✗ 学生过程
f(x)=2sin(x+π/3)——直接把 b/a 代入 arctan
✓ 正确过程
f(x)=2(½sin x-½√3cos x)=2(sin x·cos π/3-cos x·sin π/3)
=2 sin(x - π/3)

错误根源：辅助角公式 asin x + bcos x = √(a²+b²) sin(x + φ) 中，tan φ = b/a，但 φ 的象限由 (a, b) 的符号共同决定。直接用 arctan(b/a) 只能得到一四象限的值，误把 φ = -π/3 算成了 +π/3。

终边法：把 a 和 b 当作坐标点 (a, b)，该点象限就是 φ 终边所在象限。a=1, b=-√3 → 点 (1, -√3) 在第四象限 → φ = -π/3。

第 18 题 · 解三角形实际应用（解答 12 分，得 3 分） | 题意理解偏差 · 中档偏难

考查点：将实际方位角转化为三角形内角，用正余弦定理求解。

错误表现：方位角标注混乱，三角形内角识别错误，式列反了。

标准流程：①画草图标方位角 → ②利用平行线性质转内角 → ③选定理列式 → ④验算。

关键提醒：不要在脑子里转化方位角，必须画出来。草稿纸就是用来画的。

计算粗心汇总——多处失分约 8 分

第 13 题填空代入符号反了、第 19 题解答最后一步计算错误、第 20 题时间紧抄错数字。草稿书写工整是优点，但缺少逆运算检验的习惯。如果每道大题做完后花 30 秒代一个特殊值，这 8 分至少能追回 5 分。

四、解题方法模板（针对本次失分点）
模板 1辅助角公式 · 终边法
1提取系数：A = √(a² + b²)，提取后化为 A( a/A·sin x + b/A·cos x )
2画点定角：将 (a, b) 看作坐标点，该点所在象限就是 φ 的终边象限
3写出结果：f(x) = A sin(x + φ)，其中 cos φ = a/A, sin φ = b/A
4验算：代 x = 0 检查两边是否相等
模板 2三角函数图像平移 · 三步法
1展开形式：将函数写为 y = A sin[ω(x + φ/ω)] + k
2对 x 操作：左移 → x 替换为 x + 平移量；右移 → x 替换为 x - 平移量
3化简并验算：代 x = 0 检查原函数和新函数的关系
模板 3向量建系 · 最优化原则
1找垂直：图形中是否有互相垂直的线段？有则用它们作坐标轴
2定原点：选图形顶点作原点，而非内部点，避免坐标出现复杂值
3标坐标：确保尽可能多的点在坐标轴上，减少参数数量
4比较：养成用两种不同建系方式做同一道题的习惯，建立"最优"直觉
模板 4解三角形应用题 · 四步转化法
1画图标注：画出实际场景图，将方位角、仰角、俯角等标注在图上
2转内角：利用"两直线平行内错角相等""互补角"等将方位角转为三角形内角
3选定理：已知两边及夹角 → 余弦定理；已知两角一边 → 正弦定理
4验算：检查三角形三内角之和是否为 180°，数值是否合理
模板 5符号判断 · 象限法
1一全正、二正弦、三正切、四余弦——牢记四个象限的三角函数正负分布
2凡涉及开方（如用平方关系求 sin/cos/tan），必须先确定象限再取正负号
3已知 tan 求 sin cos 时，联立 tan = sin/cos 和 sin² + cos² = 1，解出后再定号
