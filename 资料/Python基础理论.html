01 Python 语言概述

Python 是一种解释型、面向对象、高级编程语言，由 Guido van Rossum 于 1991 年首次发布。其设计哲学强调代码可读性和简洁性，被称为"可执行的伪代码"。

  • 解释型：无需编译，逐行解释执行
  • 动态类型：变量类型在运行时确定，无需显式声明
  • 垃圾回收：自动管理内存，无需手动释放
  • 胶水语言：可轻松调用 C/C++ 等语言编写的库
  • 跨平台：Windows / macOS / Linux 均可运行
例1请简述 Python 的优缺点
优点：语法简洁、开发效率高、生态丰富（PyPI 超过 20 万包）、跨平台、社区活跃。
缺点：运行速度较慢（解释型+GIL 限制多线程）、移动端支持弱、底层控制能力弱。
▶ 查看解析
Python 的优势在于快速开发和数据处理/ML 领域，但在高性能计算、系统编程等场景需要结合 C/C++ 扩展。

02 基本语法与命名规范

  • 缩进：Python 使用缩进（通常 4 空格）表示代码块，不用 {} 或 begin/end
  • 注释：# 单行注释，''' 或 """ 多行注释/文档字符串
  • 标识符：由字母、数字、下划线组成，不能以数字开头，区分大小写
  • 关键字：if、for、while、def、class、import 等 35 个
  • 命名规范：变量/函数用 snake_case，类用 CamelCase，常量用 UPPER_CASE

03 数据类型与变量

Python 内置核心类型：

  • 不可变类型：int、float、bool、str、tuple、frozenset
  • 可变类型：list、dict、set、bytearray
  • NoneType：None 表示空值
  • 类型转换：int()、float()、str()、list()、bool() 等
  • 动态绑定：变量是对象的引用，赋值即绑定
例3写出以下代码输出
a = [1, 2, 3]
b = a
b.append(4)
print(a)
print(b)
▶ 查看解析
输出 [1, 2, 3, 4] 两次。
b = a 是引用赋值，b 和 a 指向同一个列表对象。修改可变对象会反映在所有引用上。若只想复制值，应使用 b = a[:] 或 b = a.copy()。

04 运算符与表达式

  • 算术：+ - * /（浮点除）//（整除）%（取余）**（幂）
  • 比较：== != > < >= <=，可链式比较如 a < b <= c
  • 逻辑：and or not（短路求值）
  • 位运算：& | ^ ~ << >>
  • 成员/身份：in not in is is not
  • 海象运算符 (3.8+)：if (n := len(x)) > 5: ...
例5表达式求值
计算：17 // 3、17 % 3、17 / 3、2 ** 3 ** 2
▶ 查看解析
17 // 3 = 5（整除，向下取整）
17 % 3 = 2（余数）

例6短路求值
def f():
    print("f called")
    return True
def g():
    print("g called")
    return False
result = g() and f()
print(result)
▶ 查看解析
输出：

False
and 是短路运算符：g() 返回 False 后直接短路，f() 不会被调用。类似地，or 在第一个参数为 True 时短路。

05 字符串操作

  • 定义方式：单引号 '...'、双引号 "..."、三引号 '''...''' / """..."""
  • 转义字符：\n（换行）、\t（制表）、\\（反斜杠）
  • 原始字符串：r"raw\nstring" 不转义
  • f-string (3.6+)：f"value is {x}"，支持表达式 f"{a + b:.2f}"
  • 常用方法：.upper()、.lower()、.strip()、.split()、.join()、.replace()、.find()、.startswith()
  • 切片：s[start:stop:step]
例7字符串反转
s = "Python"，写表达式反转得到 "nohtyP"
▶ 查看解析 
s[::-1]  # 'nohtyP'
step = -1 表示从右向左取全部字符。这是 Python 中反转序列最简洁的方式。
例8f-string 格式化
name = "Alice"
score = 87.5
print(f"{name:10s} 得分 {score:.1f}")
▶ 查看解析
输出：Alice 得分 87.5
:10s 表示字符串占 10 个字符宽度（左对齐），:.1f 表示保留 1 位小数。f-string 从 Python 3.6 起是推荐的格式化方式，比 % 和 .format() 更直观高效。

06 流程控制

  • if-elif-else：条件分支，注意 elif 不是 else if
  • for 循环：遍历可迭代对象，配合 range() 用于次数循环
  • while 循环：条件满足时持续执行
  • 循环控制：break（跳出当前层）、continue（进入下一次迭代）
  • else 子句：循环未被 break 中断时执行
  • pass：空操作占位符
  • match-case (3.10+)：模式匹配，类似 switch
例9for-else 用法
查找列表 [3, 7, 12, 5] 中是否有能被 3 整除的数，并打印结果。
▶ 查看解析 
nums = [3, 7, 12, 5]
for n in nums:
    if n % 3 == 0:
        print(f"找到: {n}")
        break
else:
    print("没有能被3整除的数")
for-else 的 else 分支仅在循环 未被 break 时执行。上面代码会输出 找到: 3。
例10列出 range(10) 中所有奇数
要求：用 for 循环 + if 实现，单行写法也可。

# 传统写法
for i in range(10):

列表推导式更简洁高效，是 Python 处理过滤转换操作的首选方式。

07 列表、元组、字典、集合

  • 列表 [ ]：可变、有序、可重复。常用 .append()、.extend()、.insert()、.pop()、.remove()、.sort()
  • 元组 ( )：不可变、有序、可哈希（可作为字典键）。拆包 a, b = (1, 2)
  • 字典 {k:v}：键值对、可变、键唯一且可哈希。3.7+ 保持插入顺序。.get()、.keys()、.values()、.items()
  • 集合 { }：无序、不重复。交集 &、并集 |、差集 -、对称差 ^
  • 推导式：[x*2 for x in range(10)]、{k:v for k,v in zip(keys,vals)}
例11a = [1, 2, 3]; b = a[:] — b 和 a 是同一个对象吗？
再问：修改 b[0] = 99 后 a[0] 是多少？
▶ 查看解析
a[:] 是浅拷贝，b 是新的列表对象。修改 b[0] 不影响 a，a[0] 仍是 1。
但对于嵌套列表（如 [[1,2], [3,4]]），浅拷贝只拷贝外层，内层仍共享引用，此时需用 copy.deepcopy()。
例12统计字符串中每个字符出现次数
s = "hello world"，输出为字典形式。
▶ 查看解析 
s = "hello world"
# 方法1：for 循环
count = {}
for ch in s:
    count[ch] = count.get(ch, 0) + 1

# 方法2：collections.Counter

dict.get(key, default) 是安全的取值方式，键不存在时返回默认值。生产环境推荐 Counter，它专门做计数。

08 函数与作用域

  • 定义：def 函数名(参数):
  • 参数类型：位置参数、默认参数、关键字参数、可变参数 *args、关键字可变参数 **kwargs
  • 返回值：函数可返回多个值（实际是元组）
  • 作用域规则 LEGB：Local → Enclosing → Global → Built-in
  • global / nonlocal：声明非局部变量
  • lambda：lambda x: x * 2 匿名函数
  • 装饰器：使用 @decorator 语法增强函数功能
  • 生成器：使用 yield 的惰性求值函数
例13以下代码输出什么
x = 10
def f():
    x = 20
    def g():
        nonlocal x
        x = 30
    g()
    print(x)
f()
print(x)
▶ 查看解析
输出 30 和 10。
nonlocal x 引用的是外层函数 f 的局部变量 x，将 f 作用域内的 x 改为 30。全局变量 x = 10 不受影响。
例14可变默认参数的陷阱
def f(x=[]):
    x.append(1)
    return x
print(f())
print(f())
print(f())
▶ 查看解析
输出： 
[1]
[1, 1]
[1, 1, 1]
默认参数在函数定义时求值一次，而不是每次调用时新建。可变默认参数会被多次调用累积修改。
最佳实践：def f(x=None): if x is None: x = []
例15编写一个装饰器，打印函数执行时间
用 time 模块实现。
▶ 查看解析 
import time
def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f"{func.__name__} 耗时 {time.time()-start:.4f}s")
        return result
    return wrapper

@timer
def slow_func():
    time.sleep(0.5)

slow_func()  # 输出: slow_func 耗时 0.5002s
*args 接收位置参数，**kwargs 接收关键字参数，使得装饰器可以适配任意签名的函数。

09 面向对象编程

  • 类定义：class ClassName:，__init__ 构造方法
  • self：实例方法的第一个参数，指向实例本身
  • 继承：class A(B):，支持多继承，super() 调用父类
  • 封装：单下划线 _x 表示保护，双下划线 __x 触发名称修饰
  • 特殊方法：__str__、__repr__、__len__、__getitem__、__call__ 等
  • 类方法/静态方法：@classmethod 操作类，@staticmethod 独立函数
  • 属性装饰器：@property 将方法变成属性访问
  • 鸭子类型："如果它走路像鸭子、叫声像鸭子，那它就是鸭子"——关注行为而非类型
MRO（Method Resolution Order）：多继承时，Python 使用 C3 线性化算法确定方法搜索顺序，可通过 ClassName.__mro__ 查看。
例16实现一个 BankAccount 类
要求有 owner、balance 属性，deposit(amount)、withdraw(amount) 方法，且余额不能为负。
▶ 查看解析 
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.__balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("存款金额必须为正")
        self.__balance += amount

    def withdraw(self, amount):
        if amount > self.__balance:
            raise ValueError("余额不足")
        self.__balance -= amount

    @property
    def balance(self):
        return self.__balance

    def __str__(self):
        return f"{self.owner} 账户余额: {self.__balance:.2f}元"

acct = BankAccount("张三", 1000)
acct.deposit(500)
acct.withdraw(200)
print(acct)  # 张三 账户余额: 1300.00元
使用 __balance 将余额私有化，通过 @property 提供只读访问，确保数据封装。
例17MRO 与 super() 调用顺序
class A:
    def f(self): print("A")
class B(A):
    def f(self): print("B"); super().f()
class C(A):
    def f(self): print("C"); super().f()
class D(B, C):
    def f(self): print("D"); super().f()
D().f()
▶ 查看解析
输出顺序：D → B → C → A
D.__mro__ 为 (D, B, C, A, object)。
Python 的 super() 按 MRO 顺序调用下一个类，而非简单地调用父类。这是 C3 线性化的结果，保证了所有父类仅被调用一次。

11 文件操作与异常处理

  • 文件打开：open(filename, mode)，mode: r 读、w 写、a 追加、b 二进制、+ 读写
  • 上下文管理器：with open(...) as f: 自动关闭文件
  • 读取：.read()、.readline()、.readlines()；直接遍历文件对象
  • 写入：.write()、.writelines()
  • 异常处理：try-except-else-finally
  • 常见异常：ValueError、TypeError、IndexError、KeyError、FileNotFoundError、AttributeError
  • 自定义异常：继承 Exception 类
  • raise：主动触发异常
例20安全的文件读取
读取 data.txt 中的全部内容，处理文件不存在的异常。
▶ 查看解析 
try:
    with open('data.txt', 'r', encoding='utf-8') as f:
        content = f.read()
        print(content)
except FileNotFoundError:
    print("文件不存在")
except PermissionError:
    print("无权限读取")
else:
    print("文件读取成功")
finally:
    print("操作结束")
with 语句确保文件正确关闭（即使发生异常）。encoding='utf-8' 避免中文乱码。else 分支在没有异常时执行，finally 始终执行。
例21自定义异常：余额不足
定义一个 InsufficientBalanceError 并抛出的场景。
▶ 查看解析 
class InsufficientBalanceError(Exception):
    def __init__(self, balance, amount):
        self.balance = balance
        self.amount = amount
        super().__init__(f"余额不足: 当前 {balance}元, 需要 {amount}元")

def withdraw(balance, amount):
    if amount > balance:
        raise InsufficientBalanceError(balance, amount)
    return balance - amount

try:
    withdraw(100, 200)
except InsufficientBalanceError as e:
    print(e)
自定义异常继承 Exception，构造函数中传入关键数据便于上层捕获时排查。
